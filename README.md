### 🧠 Czym się zajmuję

Buduję systemy, w których **wiele modeli AI pracuje razem jako zorganizowany zespół** —
nie pojedynczy asystent.

- 🌉 **Most LLM (bridge)** — 5 dostawców / 12 modeli z warstwowym failoverem w trakcie łańcucha zapytań
- ⌨️ **Coding-swarm** — pipeline kodujący z rolami przypiętymi do modeli, dobór przez benchmark
- 🏆 **Arena** — tryb turniejowy: 6 modeli konkuruje o jeden artefakt, mechaniczny sędzia + 2 krytyków
- 🔎 **Hybrid RAG** — BM25 + wektor (fuzja RRF) ze scoringiem świeżości i kanoniczności źródeł
- 🪤 **Bramkowany pipeline badawczy** — 86 przebadanych hipotez przez ciąg testów obalających
- 🧰 **Własne narzędzia CLI** — scrapery + automatyczne notatki, meta-harness agentowy (wdrożony i wyaudytowany)

> Wykształcenie techniczne (technik mechatronik) daje mi inżynierską dyscyplinę:
> **weryfikuję wyniki, zamiast im ufać.**
